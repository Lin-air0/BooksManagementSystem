# 技术栈选型说明

## 一、技术栈概述

本图书借阅信息管理系统采用以下技术栈：
- **前端**：Vue 2.6.11 + Tailwind CSS 2.2.17 + ECharts 6.0.0
- **后端**：Node.js 18.x + Express 4.18.2
- **数据库**：MySQL 8.0+
- **部署环境**：Windows/Linux + Nginx

## 二、选型理由

### 1. 前端技术栈

#### Vue 2.6.11
- **成熟稳定**：Vue 2已发布多年，生态完善，社区活跃，文档齐全
- **性能优越**：响应式数据绑定和虚拟DOM提供良好性能
- **Windows兼容**：Vue CLI和相关工具在Windows环境下正常工作
- **学习成本低**：语法简洁直观，对新手友好
- **组件化开发**：支持封装复用组件，提高开发效率

#### Tailwind CSS 2.2.17
- **实用优先**：提供大量原子类，无需编写自定义CSS
- **响应式设计**：内置响应式工具类，轻松适配不同屏幕尺寸
- **易于定制**：支持通过配置文件自定义主题和工具类
- **Windows兼容**：通过npm安装，在Windows环境下正常工作
- **与Vue集成良好**：有成熟的Vue插件和示例

#### ECharts 6.0.0
- **功能强大**：支持多种图表类型，满足数据可视化需求
- **文档完善**：提供详细的API文档和示例
- **社区活跃**：问题能快速得到解答
- **Windows兼容**：纯JavaScript实现，不依赖特定操作系统
- **与Vue集成简单**：有官方Vue组件库

#### Axios 1.11.0
- **功能丰富**：支持拦截器、转换器等高级功能
- **Promise支持**：基于Promise的HTTP客户端
- **跨平台**：同时支持浏览器和Node.js环境
- **易于使用**：API简洁明了

#### XLSX 0.18.5
- **功能全面**：支持Excel文件的读写操作
- **兼容性好**：支持多种Excel格式（.xls, .xlsx）
- **性能优秀**：处理大数据量时表现良好

### 2. 后端技术栈

#### Node.js 18.x
- **跨平台**：基于JavaScript，可在Windows/Linux环境下无缝运行
- **高性能**：非阻塞I/O模型，适合处理并发请求
- **生态丰富**：npm拥有大量第三方库
- **统一语言**：前后端均使用JavaScript，降低学习成本
- **Windows支持**：官方提供Windows安装程序和详细文档

#### Express 4.18.2
- **轻量级**：简单灵活，不强制特定目录结构
- **中间件机制**：易于扩展和定制
- **路由系统**：简洁的路由定义方式
- **Windows兼容**：完全支持Windows环境
- **文档完善**：有大量教程和示例

#### MySQL 8.0+
- **成熟稳定**：广泛应用的关系型数据库
- **Windows/Linux兼容**：提供多平台安装程序
- **性能优化**：支持索引、事务等高级特性
- **外键支持**：满足图书借阅系统的关联需求
- **社区支持**：有丰富的学习资源和问题解答

#### XLSX库
- **数据处理**：用于Excel文件的导入导出功能
- **格式支持**：支持多种Excel格式
- **集成简单**：易于与Node.js集成

#### Multer
- **文件上传**：处理文件上传功能
- **安全可靠**：提供文件过滤和大小限制功能

### 3. 数据库

#### MySQL 8.0+
- **成熟稳定**：广泛应用的关系型数据库
- **跨平台兼容**：支持Windows和Linux环境
- **性能优化**：支持索引、事务等高级特性
- **外键支持**：满足图书借阅系统的关联需求
- **社区支持**：有丰富的学习资源和问题解答

### 4. 部署环境

#### Windows/Linux
- **企业级支持**：微软和Linux发行版提供专业支持
- **安全性**：内置防火墙和安全功能
- **兼容性**：支持各种企业应用
- **易用性**：图形界面管理，降低维护成本

#### Nginx
- **高性能**：处理静态资源和反向代理能力强
- **轻量级**：占用资源少
- **稳定性**：经过实践检验的稳定架构
- **跨平台支持**：支持Windows和Linux环境

## 五、环境配置要点

1. **Node.js安装**：使用官方安装程序，勾选"Add to PATH"
2. **Git配置**：设置正确的换行符处理方式（autocrlf = true）
3. **MySQL配置**：确保服务正常启动，配置防火墙允许3306端口
4. **Nginx配置**：修改conf/nginx.conf文件，设置反向代理规则
5. **环境变量**：确保所有工具的路径已添加到系统环境变量
