# 前端数据展示问题修复计划

## 问题诊断结果

### 当前状态
- ✅ 后端API正常：GET /api/readers 返回正确数据格式
- ✅ 代理配置正确：vue.config.js配置无误
- ✅ 前端组件结构完整：ReaderManage.vue包含完整的数据处理逻辑
- ⚠️ 数据展示异常：页面显示空白或加载状态

### 根本原因分析

#### 1. 数据字段映射问题
**后端返回格式**：
```json
{
  "code": 200,
  "data": {
    "list": [
      {
        "reader_id": 1,
        "name": "张三",
        "student_id": "2024001",
        "type": "student",
        "email": "zhangsan@example.com",
        "phone": "13800138001",
        "created_at": "2025-08-30T13:51:15.000Z"
      }
    ],
    "total": 8
  }
}
```

**前端模板使用字段**：
- `reader.reader_id` ✓ 匹配
- `reader.name` ✓ 匹配  
- `reader.student_id` ✓ 匹配
- `reader.type` ⚠️ 后端返回"student"，前端需要显示"学生"
- `reader.email` ✓ 匹配
- `reader.phone` ✓ 匹配
- `reader.created_at` ✓ 匹配
- `reader.gender` ❌ 后端无此字段，前端模板中使用了

#### 2. 类型显示转换问题
- 后端：`type: "student"` / `type: "teacher"`
- 前端期望显示："学生" / "教师"

#### 3. 缺失字段处理
- `gender`字段在后端数据中不存在，但前端模板引用了
